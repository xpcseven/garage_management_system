# وصول رسالة التفعيل إلى صندوق الوارد (Inbox)

## لماذا تذهب الرسالة إلى «غير المرغوب فيها»؟

السبب الأكثر شيوعاً في مشروعك:

| المشكلة | التأثير |
|--------|---------|
| الإرسال من `@gmail.com` والرابط يشير إلى `ashuor.com` | Gmail يعتبرها مشبوهة |
| حساب Gmail شخصي (`tourism.noreplay@gmail.com`) | غير مخصص للإرسال التجاري |
| خطأ إملائي في البريد (`noreplay` بدل `noreply`) | يقلل الثقة |
| عدم وجود SPF/DKIM/DMARC لنطاق `ashuor.com` | تصنيف كسبام |

**الحل الجذري:** الإرسال من بريد على **نطاقك** `ashuor.com` مع توثيق DNS.

---

## الحل المُفضّل: Resend + نطاق ashuor.com (مجاني للبداية)

### 1) إنشاء حساب
- https://resend.com
- أنشئ API Key

### 2) إضافة النطاق
- في Resend → **Domains** → Add `ashuor.com`
- أضف سجلات DNS التي يعرضها Resend (SPF, DKIM, ويفضل DMARC)

### 3) إعداد `.env` على السيرفر

```env
RESEND_API_KEY=re_xxxxxxxxxxxx
RESEND_FROM_EMAIL=Ashuor Tourism <noreply@ashuor.com>
EMAIL_REPLY_TO=support@ashuor.com
NEXTAUTH_URL=https://tr.ashuor.com
EMAIL_BASE_URL=https://tr.ashuor.com
```

### 4) أعد تشغيل السيرفر

```bash
npm run dev
# أو على الإنتاج
npm run build && npm start
```

النظام يستخدم **Resend أولاً** تلقائياً عند وجود `RESEND_API_KEY`.

---

## بديل: بريد على استضافتك (SMTP)

إذا لديك بريد `noreply@ashuor.com` من الاستضافة:

```env
SMTP_HOST=mail.ashuor.com
SMTP_PORT=587
SMTP_SECURE=false
SMTP_USER=noreply@ashuor.com
SMTP_PASS=your-password
SMTP_FROM=Ashuor Tourism <noreply@ashuor.com>
EMAIL_REPLY_TO=support@ashuor.com
NEXTAUTH_URL=https://tr.ashuor.com
```

تأكد من تفعيل SPF/DKIM من لوحة الاستضافة.

---

## Gmail (تطوير فقط — ليس للإنتاج)

Gmail مناسب للاختبار المحلي، لكن **غالباً يذهب للسبام** عند الإرسال لمستخدمين حقيقيين.

```env
GMAIL_USER=tourism.noreplay@gmail.com
GMAIL_APP_PASSWORD=xxxxxxxxxxxxxxxx
```

للإنتاج استخدم Resend أو Google Workspace على `@ashuor.com`.

---

## Google Workspace (بديل مدفوع)

- بريد `noreply@ashuor.com` عبر Google Workspace
- App Password + SMTP
- ثقة أعلى من Gmail المجاني

---

## بعد الإعداد

1. سجّل حساباً تجريبياً
2. تحقق أن الرسالة في **Inbox**
3. إن ظهرت في Spam مرة واحدة: «Report not spam» — يساعد Gmail لاحقاً

اختبار SMTP:

```bash
node scripts/test-smtp.js
node scripts/test-send-email.js your@email.com
```

## ملخص

| البيئة | الإعداد |
|--------|---------|

| استضافة | SMTP على `mail.ashuor.com` |
| تطوير محلي | Gmail (قد يذهب للسبام) |
